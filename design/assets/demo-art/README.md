# CreatorMilestone demo artwork

These images are AI-generated sample artwork for the CreatorMilestone demo. They were generated with OpenAI's built-in `image_gen` tool; the tool did not report a model name. The finished illustration was used as the image reference for the sketch and hoodie variation. The generated 1086 × 1448 images were resized to 1200 × 1600 and color-quantized for web delivery; thumbnails were resized to 480 × 640 and quantized.
